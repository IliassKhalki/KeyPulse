# Changelog

All notable KeyPulse changes are documented here.

## Unreleased

- Clarified ongoing maintenance notes for the portable Windows build.
- Added portable-build troubleshooting guidance.
- Kept the public project focused on the native Windows desktop application.

## 0.1.0 - 2026-06-08

- Added automatic supported-game process detection and per-launch sessions.
- Added persistent SQLite history for playtime, keyboard presses, and mouse inputs.
- Added the dark KeyPulse dashboard, charts, heatmaps, and recent-session history.
- Added the draggable live keyboard, mouse, and XInput controller overlay.
- Added system tray support, single-instance protection, and Windows startup support.
- Added the branded launch screen and embedded application icon.
- Added a portable Windows build for direct download.
